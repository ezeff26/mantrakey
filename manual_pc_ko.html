낭아타키 PC 입력기 사용설명서

Windows에서 CapsLock 한 번으로 미얀마어를 입력하는 방법. 자판 배열, 입력 규칙, 요령을 한곳에 정리했습니다.

목차 1. 시작하기 2. 켜기와 끄기 3. 화면 키맵(HUD) 4. 자음과 ▶ 키 5. 모음·부호 키 6. ေ 는 먼저 친다 7. 파찌이+ 키: 겹자음과 특수문자 8. 문장부호 9. 숫자 10. 백스페이스 요령 11. 따라 쳐 보기 12. 문제 해결 13. 한 장 요약

1시작하기

설치 과정이 따로 없습니다. 파일을 한 폴더에 두고 실행하면 끝입니다.

  1. 배포 폴더 안의 파일을 모두 같은 폴더에 둡니다.
    nangathakey_beta.exe, pc_map.png, pc_plus.png, logo.ico (그림 파일이 없으면 화면 키맵이 뜨지 않습니다)
  2. nangathakey_beta.exe를 실행합니다. 화면 오른쪽 아래 작업표시줄 트레이에 낭아타키 아이콘이 나타납니다.
  3. Windows 입력 언어를 영어(English)로 둡니다. 한글 IME 등 다른 입력기가 켜져 있으면 낭아타키가 동작하지 않습니다.
  4. CapsLock을 누르면 미얀마어 입력이 시작됩니다.
왜 영어 키보드여야 하나요?낭아타키는 영문 자판 위에 미얀마 문자를 얹는 방식입니다. 한국어 사용자라면 한/영 전환이 아니라 Windows 입력 언어 자체를 영어로 바꿔 주세요(Win+Space).

2켜기와 끄기

CapsLock이 낭아타키 스위치입니다.

누르는 키동작
CapsLock낭아타키 켜기 / 끄기. 켜면 화면 아래에 키맵이 나타납니다.
Shift + CapsLock원래의 CapsLock(영문 대문자 고정)이 필요할 때 사용합니다.
트레이 아이콘 우클릭현재 켜짐/꺼짐 상태 확인, 키맵 자동 표시 설정, 종료(Exit).

트레이 메뉴는 실제 사용자를 위해 미얀마어로 표시됩니다. ဖွင့်ထားသည် = 켜짐, ပိတ်ထားသည် = 꺼짐, ကီးဘုတ်ပုံ (HUD) အလိုအလျောက် ပြရန် = 키맵 자동 표시.

3화면 키맵(HUD)

낭아타키가 켜져 있으면 화면 아래쪽 가운데에 자판 그림이 떠서 입력을 도와줍니다.

10초 뒤 자동으로 숨음입력이 없으면 10초 뒤 키맵이 사라집니다. 아무 키나 치면 다시 나타납니다.
스페이스로 다시 부르기키맵이 숨은 상태에서 누르는 첫 스페이스는 공백을 넣지 않고 키맵만 다시 띄웁니다.
언어를 바꾸면 따라 숨음영어 외의 입력기로 바꾸면 곧바로 숨고, 영어로 돌아오면 다시 나타납니다.
자동 표시 끄기자판을 다 외웠다면 트레이 메뉴에서 자동 표시를 끌 수 있습니다. 설정은 저장됩니다.
파찌이+ 키맵은 항상 보입니다자동 표시를 꺼 두어도 O(파찌이+ 키)를 누르면 파찌이+ 키맵만은 반드시 나타납니다. 파찌이+ 쪽 배열은 자주 쓰지 않아 외우기 어렵기 때문입니다.

4자음과 ▶ 키

미얀마 자음 33개를 왼손 13개 키에 자음표의 열을 기준으로 묶어 두었습니다. 키를 누르면 그 묶음의 첫 글자(검은 글자)가 나오고, K(▶)를 누를 때마다 다음 글자(파란 글자)로 바뀝니다.

묶는 방법

8문장부호

/와 ;는 바로 앞 글자가 미얀마 글자일 때만 미얀마 부호로 바뀝니다. 공백·숫자·영문·기호 뒤에서는 원래대로 /, ;가 입력됩니다.

/ : 쉼표 → 마침표 → 말줄임표

ကား။미얀마 글자 뒤에서 / 연타
/ကား၊
/ကား။
/ကား...
/ကား....

한 번 = 쉼표 ၊, 두 번 = 마침표 ။, 세 번 = 말줄임표 ..., 그 뒤로 누를 때마다 점이 하나씩 늘어납니다.

슬래시가 필요했다면쉼표(၊)가 찍힌 바로 다음에 BS를 누르면 지워지지 않고 /로 되돌아갑니다. 마침표 단계까지 갔다면 일반 삭제입니다.

; : 성조 부호

미얀마 글자 뒤에서는 း(한 번) / ့(두 번), 그 외에는 ;입니다.

9숫자

미얀마에서도 가격·전화번호·날짜에는 아라비아 숫자를 주로 쓰기 때문에, 기본은 아라비아 숫자입니다.

누르는 방법결과
숫자 키를 짧게 톡1 2 3 (아라비아 숫자)
숫자 키를 0.35초 이상 꾹၁ ၂ ၃ (미얀마 숫자)

꾹 누르고 있어도 미얀마 숫자는 한 번만 입력됩니다. 0~9 모두 같습니다: ၀ ၁ ၂ ၃ ၄ ၅ ၆ ၇ ၈ ၉

대부분은 한 글자씩 지워지지만, ေ가 들어간 음절에서는 다시 고치기 쉽도록 지워집니다.

지금 화면BS 후설명
ကောကေ뒤에 붙은 모음부터 지웁니다.
ကြေကေ결합 부호를 지웁니다.
ကေေ자음만 빠지고 ေ는 남아 있어, 바로 다른 자음을 치면 됩니다.
ကား၊ကား/쉼표 직후의 BS는 /로 되돌립니다 (8장).
조합이 꼬였을 때마우스 클릭, 방향키, Tab, Esc, Ctrl+C/V/Z 등을 누르면 낭아타키의 조합 상태가 초기화됩니다. 이미 입력된 글자는 그대로 남습니다.

12문제 해결

CapsLock을 눌러도 영문만 입력돼요.
Windows 입력 언어가 영어인지 확인하세요. 한국어 IME(한글 모드든 영문 모드든)에서는 동작하지 않습니다. 트레이 아이콘에 마우스를 올려 켜짐 상태인지도 확인해 보세요.
화면 키맵이 안 보여요.
① 10초 동안 입력이 없어 숨은 상태일 수 있습니다. 스페이스를 한 번 누르세요. ② 트레이 메뉴에서 자동 표시가 꺼져 있을 수 있습니다. ③ pc_map.png, pc_plus.png가 exe와 같은 폴더에 있는지 확인하세요.
스페이스를 눌렀는데 공백이 안 들어가요.
키맵이 숨어 있을 때의 첫 스페이스는 키맵을 다시 부르는 데 쓰입니다. 한 번 더 누르면 공백이 입력됩니다.
숫자를 쳤는데 미얀마 숫자가 나와요.
키를 0.35초 이상 누르고 있으면 미얀마 숫자가 됩니다. 조금 더 짧게 톡 눌러 주세요.
/ 나 ; 를 그대로 쓰고 싶어요.
공백 뒤에서 치면 그대로 입력됩니다. 미얀마 글자 바로 뒤라면 / 다음 BS로 /를 얻을 수 있습니다. 영문이 많이 섞인 글이라면 CapsLock으로 잠깐 꺼 두는 것이 편합니다.
소수점이나 천 단위 쉼표는 어떻게 치나요?
숫자 바로 뒤에서 . ,를 누르면 됩니다. 예: 3 . 5 → 3.5 (8장 참고)
대문자를 연속으로 쓰고 싶어요.
Shift+CapsLock이 원래의 CapsLock 역할을 합니다.
